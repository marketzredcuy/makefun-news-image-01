# news-image-01 — v4 classic front page

One image summing up the world's news of Friday 13 November 2026:
a classic newspaper front page with 30 stories — a globe icon +
"THE WORLD'S NEWS" masthead + dark-blue nav bar, 8 main story cards
(FAA halts all US departures, Iran radar in Bahrain, Trump-Xi-Putin
APEC, SpaceX Starship Flight 15, Ukraine's 1,200-drone attack, Nvidia
CEO resigns, Microsoft 365 outage day 2, Pope Leo XIV in Peru), each
with a numbered tag + category ribbon + image + headline + explainer,
plus 22 more stories in the "ALSO ON FRIDAY" list in 3 columns, and
a world-landmarks skyline strip at the bottom. All facts verified
against real reporting of the day.

`main.py` copies the pre-composed `entry.png` to
`$MAKEFUN_OUTPUT_DIR/entry.png` and verifies size and format.
